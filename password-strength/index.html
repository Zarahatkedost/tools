Password strength

Type a password and see how long it would survive a cracking attempt.

What this does. Estimates how strong a password is using its length and character variety (its entropy), shows an estimated crack time against a modern offline attack (~10 billion guesses/second), and lists exactly what would make it stronger. It also catches the classic weaknesses: common passwords, keyboard runs like qwerty, repeated characters and sequences. Your password never leaves this page — nothing is sent, stored, or logged anywhere. Still, never test your real current password anywhere, even here — test candidates instead. Need a strong one generated? Use the Crypto & ID tool.
