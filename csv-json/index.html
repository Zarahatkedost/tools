CSV ↔ JSON

Paste one side, get the other — spreadsheet data to JSON and back.

What this does. Converts CSV (the format Excel and Google Sheets export) into JSON, and JSON back into CSV. It uses a proper CSV parser: quoted fields, commas inside values, quotes inside quotes and multi-line cells are all handled correctly — the things naive converters break on. First CSV row is treated as headers. JSON side accepts an array of objects. You can also upload a .csv or .json file, and download the result.
